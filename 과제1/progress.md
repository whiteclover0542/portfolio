## 과제 개요
링크 하나로 나의 장점과 경험을 보여주는 개인 포트폴리오 사이트 제작. 이력서 양식 복제가 아니라 공개 범위·강조할 강점·전체 분위기를 전부 직접 정해서 만드는 한 페이지짜리 사이트.

## 왜 하는가
- 무엇을 공개할지, 어떤 강점을 앞에 둘지, 어떤 분위기로 만들지 전부 내가 정한다.
- 정해진 정답 양식은 없음.
- AI를 사용한다면, 결과물을 그대로 쓰지 않고 직접 검사 → 내 판단으로 수정하는 연습.

## 최종 제출물 (2개)
1. **검증 안내서** — 어디로 가나요 / 무엇을 하나요 / 무엇이 보이면 통과인가요 / 안 될 때
2. **AI 3줄** — AI에게 맡긴 일 · 내가 판단한 일 · AI 말을 안 들은 일

> 제출 화면에는 이 두 가지만 남긴다. 그 외 자료(체크리스트 증거 파일 등)는 별도 보관.

## 과제 안내 (5단계)

### 1단계 — 대상과 공개 범위 ✅
- 하는 일: 누구에게 보여줄 페이지인지 한 문장으로 정하고, 공개할 정보와 공개하지 않을 정보를 먼저 나눈다
- 첫 행동: 대상 문장 채우기 ✅ / 공개할 것·공개하지 않을 것 각 3개씩 적기 ✅
- 통과 기준: 공개 주소가 바로 열리고 대상과 공개 범위가 화면에 보인다 — **충족**
- 막힐 때: 주소가 안 열림 → 첫 파일명이 index.html인지, 공개 폴더 최상단인지, Pages 설정 확인
- 남길 것: 공개 주소 확인 — 공개 주소가 바로 열리고 대상과 공개 범위가 화면에 보인다

### 2단계 — 말이 아니라 근거 ✅
- 하는 일: 강점이나 취향 3개를 상황·행동·결과로 바꾸고 근거를 연결한다
- 첫 행동: 세 칸(상황·행동·결과) 정리 ✅ / 최근 3개월 경험 기준으로 작성 ✅
- 통과 기준: 소개 3개와 공개 가능한 근거 1개가 같은 화면에서 연결되어 보인다 — **충족**
- 막힐 때: 쓸 경험이 없음 → 최근 3개월의 작은 완료 하나 고르기 / 근거 공개 부담 → 이름·기관·연락처 제거 후 결과 문장만 사용
- 남길 것: 공개 주소 확인 — 소개 3개와 공개 가능한 근거 1개가 같은 화면에서 연결되어 보인다

### 3단계 — 첫 화면 재구성 ✅
- 하는 일: 처음 3초 안에 누구인지·무엇을 하는지·근거 한 가지가 보이도록 첫 화면을 고친다 — WHO AM I / WHAT I DO / PROOF 라벨+숫자 구조로 히어로 구성, 대상 문장은 근거(PROOF) 아래 배치
- 첫 행동: 1366×768 스크롤 없이 확인 ✅ / 1920×1080 가로 넘침·여백 확인 ✅ (둘 다 헤드리스 Chrome 실측)
- 통과 기준: 첫 화면에 소개·활동·근거가 가로 넘침 없이 함께 보인다 — **충족**
- 막힐 때: 내용 잘림 → 세로 여백·이미지 크기 먼저 줄이기 / 내용 퍼짐 → 본문 최대 폭 지정, 가운데 정렬
- 남길 것: 공개 주소 확인 — 첫 화면에 소개·활동·근거가 가로 넘침 없이 함께 보인다

### 4단계 — 실제 결함 고치기 ✅
- 하는 일: 링크·Tab 이동·콘솔 오류·제목 순서·명암 대비를 점검하고 결함 3개 이상을 고친다 (Puppeteer 자동 점검)

| # | 결함 | 수정 전 | 수정 후 |
|---|------|---------|---------|
| 1 | `.project-index` 명암 대비 미달 | `--gray-500` on `--gray-100` = 2.74:1 | `--gray-700`로 변경 = 8.24:1 |
| 2 | `.project-note` 명암 대비 미달 | 동일 조합, 2.74:1 | `--gray-700`로 변경 = 8.24:1 |
| 3 | 공개 주소 콘솔 오류(404) | `favicon.ico` 자동 요청 실패 | 인라인 SVG favicon 추가로 요청 자체 제거 |

- 통과 기준: 화면의 링크를 한 번 누르면 연결된 내용이 바로 표시된다 — **충족** (GitHub 링크 4개 전부 200 응답, Tab 순서 정상, 헤딩 순서 정상)
- 막힐 때: 결함 찾기 어려움 → Tab 이동 위치·링크 목적지·제목 단계 확인 / 콘솔 오류 → 오류 1건씩 파일·줄 확인 후 재확인
- 남길 것: 공개 주소 확인 — 화면의 링크를 한 번 누르면 연결된 내용이 바로 표시된다

> 별도 확인된 결함(HOW I WORK 03번 빈 리스트 항목·중복 문구)은 본인이 직접 수정 예정이라 보류.

### 5단계 — 나와 연결된 재미 ✅
- 하는 일: 페이지 내용과 관계있는 상호작용 1개를 추가하고 키보드에서도 작동하게 만든다 — 강점 카드 "자세히 보기/접기" 토글
- 첫 행동: 클릭 대상이 button인지, Enter/Space로 실행되는지 검사 ✅
- 통과 기준: 상호작용을 한 번 실행하면 화면이 즉시 바뀐다 — **충족** (공개 주소에서 마우스·Enter·Space 전부 확인)
- 막힐 때: 키보드로 실행 안 됨 → button 여부, Tab 포커스, Enter/Space 각각 검사
- 남길 것: 공개 주소 확인 — 상호작용을 한 번 실행하면 화면이 즉시 바뀐다
